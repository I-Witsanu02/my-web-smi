# การปรับ Manuscript จากต้นฉบับ

ฉบับใหม่เน้น XAI และ Web Application ใช้ FocalNet เพียง checkpoint เดียว ส่วนรหัสภายในและ SHA256 อยู่ในไฟล์ provenance เพื่อให้ตรวจย้อนกลับได้ ไม่เปลี่ยนรุ่นที่ให้ผลโดยเปลี่ยนเพียงชื่อเรียก

## ผลที่คงไว้และผลที่คำนวณซ้ำ
- 260 เคส MAE 6.619 เดือน RMSE 8.795 เดือน Bias +0.755 เดือน คงจาก prediction รายบุคคลเดิม ไม่มีการฝึกใหม่
- 95% CI ของ MAE คำนวณซ้ำได้เป็น 5.937–7.351 เดือน ด้วย bootstrap 20,000 ครั้ง seed 20261105 ต้นฉบับเขียน 5.893–7.331 แต่ยังไม่มีรายละเอียดวิธีทำซ้ำ จึงระบุการเปลี่ยนแปลงนี้ชัดเจน ไม่ใช่การคัดเลือกช่วงที่สวยกว่า
- ไม่ใช้ 6.581 แทน 6.619 เพราะเป็นคนละ run ต้องมีหลักฐาน run หากต้องการเปลี่ยนผล
- ตัวเลข 182.484 เดือนจากภาพตัวอย่างเป็นผลคำนวณภาพประกอบด้วย CPU float32 ไม่ใช่ MAE ใหม่และไม่เพิ่มเข้า cohort

## ภาพที่เลือก
1. Workflow ใหม่แสดง FocalNet ตัวเดียว ไม่ใช้ป้าย YOLOv12 หรือโมเดลเปรียบเทียบจากภาพสถาปัตยกรรมเดิมโดยไม่มีหลักฐานตรงกับรุ่นที่ประเมิน
2. ภาพเต็ม Grad-CAM และ Eigen-CAM สร้างจาก checkpoint เดียวกับผลตัวเลข เก็บ raw map ในเครื่อง และบันทึก hash/ตำแหน่งกรอบ/การแสดงผลใน XAI_figure_provenance.json
3. Crop Grad-CAM ครบ 9 จุด สีแดงคือค่าตอบสนองสูงเมื่อเทียบภายใน ROI นั้น ไม่ใช่ความมั่นใจ ไม่ใช่จำนวนเดือนที่ตำแหน่งนั้นเพิ่มให้คำทำนาย
4. ภาพหน้าจอภาษาอังกฤษถ่ายจากเว็บที่เปิดในเครื่อง ใช้แสดงตำแหน่งเครื่องมือ ไม่ใช้เป็นผล clinical usability
5. ภาพ ID 2832 ของผู้เขียนเก็บเป็นต้นทางประกอบ แต่ไม่ใช้ยืนยัน checkpoint ที่เลือกเพราะยังผูก provenance ไม่ครบ ไม่มีการย้ายหรือเพิ่มจุดสีแดงด้วยมือ

## สิ่งที่ยังต้องยืนยันก่อนส่งวารสาร
- สถานะจริยธรรมยัง pending ไม่ใส่เลขอนุมัติที่ไม่มี
- ชุดข้อมูลเคยถูกตรวจผล และมี flag 15 รายที่อาจเกี่ยวกับข้อมูล initialization ต้องตรวจ membership จริง ไม่กล่าวว่าทั้ง 260 รายซ้ำกับ training
- จำนวน 3,600 augmented rows กับ 4,821 patient IDs ต้องอธิบายที่มาต่างกัน
- ไม่มี reader study, faithfulness test, clinical benefit หรือผลประเมินการเรียนรู้จาก feedback
- ผู้เขียนยืนยันสิทธิ์เผยแพร่ภาพ ข้อมูล และต้นฉบับ พร้อมรายละเอียดสาขา/ผู้ประสานงานตามวารสาร

## แนวทางภาษาที่ศึกษา ไม่คัดลอกประโยค
- Tonekaboni et al. 2019 https://proceedings.mlr.press/v106/tonekaboni19a.html ใช้แนวทางผูกคำอธิบายกับงานที่ผู้ใช้ต้องทำ แทนการอ้างว่า heatmap สร้างความเชื่อมั่นได้เอง
- Chen et al. 2022 https://www.nature.com/articles/s41746-022-00699-2 ใช้แนวทางแยกผู้ใช้ บริบท และหลักฐานประเมิน ไม่ขยายข้อกล่าวอ้างเกินการทดลอง
- Muhammad and Yeasin 2020 https://arxiv.org/abs/2008.00299 ใช้คำนิยาม Eigen-CAM เป็น principal component ของ feature ไม่เรียกว่า attribution ต่ออายุ
- Arun et al. 2021 https://pmc.ncbi.nlm.nih.gov/articles/PMC8637231/ แยกภาพที่ดูสมเหตุสมผลจากความน่าเชื่อถือที่ต้องวัดด้วยการทดลอง
- Jin et al. 2023 https://arxiv.org/abs/2202.10553 ใช้กรอบความเข้าใจและความเกี่ยวข้องกับการใช้งาน ไม่ยืมผลการทดลองของงานอื่นมาเป็นผลของเรา
